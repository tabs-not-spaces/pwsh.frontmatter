## {{NewVersion}}

Security and correctness release. Read the breaking changes before you upgrade.

### Breaking changes

- Set-FrontMatter now rejects the wildcard metacharacters '*' and '?' in
  -FilePath. A wildcard used to expand and overwrite every matching file with
  the same block. Pass one literal path.
- Set-FrontMatter now requires a .md extension on write, matching the read path.
- Set-FrontMatter now supports ShouldProcess, so -WhatIf and -Confirm work.
  Automation that runs under a global $ConfirmPreference of High now prompts.
- Pipeline input to Set-FrontMatter and Convert-FrontMatter now processes every
  object. Previously only the last object was handled.
- YAML and TOML output from Set-FrontMatter and Convert-FrontMatter now rejects
  property names that could forge keys or close the block, such as names
  containing a newline, ':' or '='. TOML keys are limited to letters, digits,
  underscores and hyphens.
- The manifest now declares PowerShellVersion 7.0 and exports only
  Get-FrontMatter, Set-FrontMatter and Convert-FrontMatter. Private helpers are
  no longer visible.

### Fixes

- Front matter values are no longer used as a regex replacement string, so '$&'
  and '$1' in a value stay literal.
- Every read and write uses -LiteralPath, so brackets in a file name work and
  path globbing cannot be triggered.
- JSON blocks are located by string aware brace counting, so nested objects no
  longer truncate the block.
- Set-FrontMatter only replaces a block that starts on the first non-empty line,
  so a thematic break in the body is not mistaken for front matter.
- String values are escaped on write and unescaped on read, including Unicode
  escapes.
- The YAML parser skips comments, keeps key order, and no longer promotes nested
  keys to the top level.
- Only whole numbers are promoted to [int]. Quoted values always stay strings.
- TOML arrays split only on commas outside quoted strings, so an item such as
  "a,b" reads back as one item.
- Writes preserve the original byte order mark and the dominant line ending,
  and go through a uniquely named temporary file that is moved over the
  original, so an interrupted or concurrent write cannot leave a half
  rewritten document or clobber an unrelated file.

### Docs

- Comment-based help added to all three public functions.
- Module and repository READMEs rewritten. LICENSE file added.
